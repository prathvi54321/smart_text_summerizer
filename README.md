# ✍️ Smart Text Summarizer
This is an AI-powered tool that takes long text as input and generates a concise summary. It's designed to help users quickly grasp the main points of any document.

## 🛠️ Features
* **Text Extraction:** Uses NLP to identify key sentences.
* **Efficient:** Reduces reading time by up to 80%.
* **Simple Interface:** Easy to run via the command line.
